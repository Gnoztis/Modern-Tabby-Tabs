# Modern Tabby Tabs

Адаптивные табы и аккордеон для WordPress: содержимое записи разбивается на
вкладки шорткодами, а на узких экранах те же блоки превращаются в аккордеон.
Без jQuery и внешних библиотек; поддержка тёмной темы и системной цветовой
схемы.

Версия 1.4.3. Требуется WordPress 7.0+ (проверено до 7.1) и PHP 8.4+.

## Установка

1. Скопировать каталог `modern-tabby-tabs` в `wp-content/plugins/`.
2. Активировать плагин в разделе «Плагины».
3. При необходимости открыть «Настройки» → «Tabby Tabs» и выбрать внешний вид.
4. Вставить шорткоды в запись или страницу.

CSS и JS подключаются только на страницах, где есть шорткод `[tabby]`.

## Шорткоды

Группа открывается `[tabby]` и закрывается `[tabbyending]`. Каждый `[tabby]`
начинает новый таб; его содержимое — обычный контент WordPress между
шорткодами.

```
[tabby title="Первый таб"]

Текст первого таба.

[tabby title="Второй таб" open="yes"]

Текст второго таба.

[tabbyending]
```

Оставляйте пустую строку до и после шорткодов: так `wpautop` не вставит
лишние теги абзацев.

### Атрибуты `[tabby]`

| Атрибут | Описание |
|---|---|
| `title` | Заголовок таба. Разрешена простая разметка: `<br>`, `<strong>`, `<em>`, `<i>`, `<span class>`, `<small>`, `<sub>`, `<sup>`. |
| `open` | `open="yes"` — таб открыт по умолчанию. |
| `icon` | Имя иконки Font Awesome без префикса, например `icon="shield-halved"`. Стиль иконок задаётся в настройках. Font Awesome подключается отдельно. |
| `ico` | Класс произвольной иконочной гарнитуры, например `ico="my-icon"`. |
| `class` | Дополнительный CSS-класс: добавляется к заголовку таба, а `<class>-content` — к его панели. |

### Открыть таб по ссылке

Параметр `?target=<slug>` открывает таб, заголовок которого совпадает со slug
(как в `sanitize_title_with_dashes()`), например `?target=second-tab`.

## Настройки

«Настройки» → «Tabby Tabs» (нужно право `manage_options`):

- **Стандартные стили** — подключать CSS плагина на сайте; снимите флажок,
  если стилизуете табы в дочерней теме.
- **Доставка CSS** — отдельный файл (кэшируется, рекомендуется) или инлайн
  внутри `<head>` без дополнительного запроса.
- **Цветовая схема** — авто (как активная тема сайта), всегда светлая, всегда
  тёмная, системная (по настройке ОС).
- **Стиль панели** — рамка (по умолчанию), плоский, акцентная полоса слева,
  мягкий фон.
- **Элемент заголовка таба** — `h1`–`h6`, `p`, `div` или `span`.
- **Стиль иконок Font Awesome** — обычные, залитые, тонкие, сверхтонкие,
  двухцветные.

Оформление использует переменные `--tabby-*`, их можно переопределить в
дочерней теме.

## Мобильные экраны

При ширине до 767px список вкладок заменяется аккордеоном: заголовки табов
становятся кнопками, панель раскрывается под своим заголовком, повторное
нажатие сворачивает её. На широких экранах работают обычные вкладки.

## Обновления

Плагин обновляется штатным механизмом WordPress из репозитория
[Gnoztis/Modern-Tabby-Tabs](https://github.com/Gnoztis/Modern-Tabby-Tabs):
берётся максимальная версия из GitHub Release и тегов (`vX.Y.Z` и `X.Y.Z`
равнозначны), архив — zip-ассет релиза или zipball победившего источника.
Предрелизы (`-beta`) и четырёхчастные версии (`1.7.0.1`) не принимаются,
поэтому достаточно поставить тег.

Проверка кэшируется на 6 часов; кнопка «Проверить обновления» в строке плагина
сбрасывает кэш и игнорирует бэкофф после ошибки.

Токен GitHub необязателен. Без него API работает анонимно — **60 запросов в
час на IP**; на общем хостинге лимит легко исчерпывается, и тогда в админке
появляется «проверка не удалась: 403 (лимит GitHub API)». С токеном лимит —
**5000 запросов в час**. Нужен fine-grained personal access token с доступом к
репозиторию и единственным правом **Contents: Read** (только чтение):

```php
// wp-config.php
define( 'MTT_GITHUB_TOKEN', '…' );
```

Токен можно задать и фильтром `mtt_github_token`. Он передаётся только запросам
к `api.github.com`/`github.com` и нигде не выводится.

## Удаление

`uninstall.php` удаляет только настройки плагина (`mrt_*`) и кэш проверки
обновлений; на multisite — на всех сайтах сети.
